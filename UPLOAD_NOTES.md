# Full project archive
All original project files are included, including model weights and experiment outputs. Large files use Git LFS.
After cloning, run: git lfs pull
The original saved_results/Models/ResNet_50.zip exceeds the GitHub personal-account single-file limit. Its complete contents are stored in ResNet_50.zip.parts/. Run python saved_results/Models/ResNet_50.zip.parts/restore.py to restore it. The script verifies SHA-256. The local original ZIP has been preserved.
